IoT with Embedded C, Arduino, and Raspberry Pi

  • By Skilled.u
  • 50+ Students

Course Description

Explore the fundamentals of Internet of Things (IoT) development with Skilled.U. Learn Embedded C programming for microcontrollers, build hardware prototypes using Arduino, and develop IoT applications with Raspberry Pi. Understand sensor integration, GPIO programming, communication protocols, MQTT, and cloud connectivity. Gain practical experience through hands-on projects and learn how connected devices collect, exchange, and process data.

Course Level: Advanced Beginner to Intermediate

What You’ll Learn in This Course?

  • Embedded C — Program microcontrollers and interface with hardware.

  • Arduino — Build prototypes using sensors and electronic components.

  • Raspberry Pi — Develop IoT applications using Python and GPIO.

  • MQTT & Connectivity — Understand device communication and messaging.

  • Cloud Integration — Connect IoT devices to cloud-based services.

Course Curriculum

This course follows a structured learning path covering embedded programming, hardware prototyping, sensor integration, device communication, and IoT application development. Practical exercises help you apply concepts and build connected-device projects.

  • Learn variables, data types, loops, and functions in Embedded C.
  • Understand microcontrollers and hardware interfacing.
  • Work with input/output pins and basic embedded programming tasks.

  • Understand Arduino boards and the development environment.
  • Connect sensors, actuators, and electronic components.
  • Build prototypes and collect sensor data.

  • Understand Raspberry Pi setup, GPIO, and Python basics.
  • Connect hardware components and process sensor data.
  • Develop IoT applications with networking and device connectivity.

  • Understand the fundamentals of device-to-device communication.
  • Explore MQTT messaging and publish-subscribe concepts.
  • Exchange data between connected IoT devices.

  • Understand how IoT devices communicate with cloud services.
  • Send and monitor device data using supported platforms.
  • Explore remote monitoring and connected-device management.

  • Design an IoT solution based on a real-world problem.
  • Integrate sensors, controllers, and communication features.
  • Test the prototype and evaluate its functionality.
